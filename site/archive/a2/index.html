威胁？泄露？深度剖析小章鱼如何让 Milthm 新团队走向崩溃

互联网小章鱼
2026年10月07日 01:43 · 专栏 cv53316951

本文主角「辣椒树」，又名「幸奈」、「YamiNa」、「互联网小章鱼」、「杉原夜季」、「Kiyotsuki」、「十返清月」，曾任职《Milthm》策划。

以下内容由知情人士提供，并经整理后发布。

————————————————————————————————

概要：

Milthm 前主创成员小章鱼，在公开账号明确表明自己退出游戏制作后，依旧不断威胁、控制、纠缠新制作组数月。索要"7万天价买断费"、"一票否决权"未果后，多次威胁团队，拒绝合理交流，擅自干涉新制作组工作，拉帮结派，多次辱骂造谣制作组成员，导致制作组无可奈何只能决定解散。

在项目面临解散之际，其依旧死心不改，多次要求制作组将游戏版权交给他处置。未果后，其在 QQ 群公开造谣辱骂制作组，在 B 站公开直播游戏制谱器内容，公开大量游戏内部资料，造成了严重后果。

————————————————————————————————

1. 尘埃落定？

曾几何时，我们以为这场持续数月的雨 EP 风波，终于要以一种体面的方式落下帷幕。此前，小章鱼已在公开账号发布退组声明，向新制作组道歉，并宣布正式退出。不久后，他前往公安机关"立案"，以法律手段相威胁，要求我下架相关动态。

这一系列操作看似流程完整、滴水不漏，表面上他仿佛已经回归了普通玩家的身份。然而，表面的和平终究只是假象。退组和道歉并没有换来彻底的切割，在"立案"与"威胁下架"的掩护下，他依然死心不改，暗中将手伸向了新制作组的正常运转……

2. 神权与钱的抉择

首先是拒绝交出贡献，以此作为要挟团队的筹码。在项目重组之际，出于合规要求，团队要求他签署《贡献转让协议》。但他拒不签字，反而抛出极为荒谬的勒索条件：

要么支付所谓的"市场价"三分之一买断（且"市场价怎么算得由他来定"，此前曾开口索要 7 万元（约为市场价两到三倍））；要么赋予他"用人一票否决权"、"收曲一票否决权"的"神权"，甚至作为一个已退组成员，还要强行介入与项目成员的直接沟通。

妄图以极度不平等的霸王条款继续掌控新制作组，稍有不从便不断纠缠、威胁，导致推进工作举步维艰。

3. 缠缠绵绵的阴影

在纠缠中，他深知自己前期的行径已导致风评受损，便企图通过造谣与制造舆论来解决自身的风评问题。他不再着眼于游戏内容本身，试图伪造雨 EP 的真实内情，将锅全部甩到制作组身上，并以此作为要挟。直言越来越不在意 Milthm 的死活了，想不出 Milthm 爆炸能给他带来的坏处。

他拒绝有效率的沟通，势必要和组内打持久战。同时，他还拉帮结派，套取新制作组内部消息，在核心组员中间散播负面情绪，妄图从内部彻底瓦解新项目组。

4. 比权利更沉重的

不仅如此，他更是将破坏的双手伸向了团队的外部合作，擅自干预新组的正常联动。

在未经过任何内部商议、甚至已无权干涉新组决策的情况下，他私自越权联系外部联动方（Simple），单方面宣布"这次选曲无效"。同时，他在群内对团队的选曲大泼脏水，用极具侮辱性的言语辱骂联动曲目是"一坨屎"，甚至傲慢地质问："是不是给你们一坨屎只要是别的游戏的你们都要？"

这种自作主张的越权行为，不仅让团队在外部合作方面前信誉受损，更让原本就举步维艰的新制作组雪上加霜。

5. 刀尖之上的舍离

在核心进度停滞、外部口碑受损、内部人心惶惶的境地下，团队已无法保证正常产出，更无力应对随时可能爆发的版权纠纷和网络风暴。最终，出于法律合规要求，新制作组在内部决定终止游戏制作。

然而可笑的是，在彻底摧毁了 Milthm 之后，他并没有如自己此前扬言的那般"毫不在意"。在项目宣告解散的当下，他反而跑到其他群聊，开启了卖惨模式，疯狂塑造自己的"受害者"形象。

他绝口不提天价买断费、一票否决权、拉帮结派等恶劣行径，反而将自己包装成"付出一切却被无情排挤"的可怜创作者，试图利用不知情的群众带偏舆论。

更令人不齿的是，他一边扮演受害者，一边露出了夺取版权的野心。他在群内质问："全部给我吧"、"你们这游戏的 IP 权力到底在谁手上？别踢皮球了！"。他试图在解散的混乱节点，将拒不交出的贡献作为筹码，逼迫团队把 IP 交给他。他根本不是来维权的，他是想趁火打劫，把全体成员的心血据为己有，自己单飞做"救世主"。这种"得不到就毁掉，毁了还要据为己有"的丑陋面目，令人作呕。

6. 灯光下，停不下的舞步

然而他的野心并未停止。他不仅在 B 站动态向公众大肆泄露 Milthm 内部资料，更在直播中"无意"展示游戏制谱器与未上线内容。

但可悲又可笑的是，这种所谓的"泄密"，并不是单纯的冲动报复，而是一场精心策划的卖惨表演。他试图借展示内部资产，向观众证明自己曾付出多少"心血"，用带血的流量为自己塑造"劳苦功高却被卸磨杀驴"的人设。

嘴里说着"想不出 Milthm 爆炸能给我带来的坏处"，手里的动作却是拿着 Milthm 的未公开内容给自己吸粉洗白。这种用毁掉项目来成全自己人设的行径，彻底触碰了道德与法律的底线。

结语：

当初小章鱼入组时，前主创曾经说过"：我们把创作游戏当作一种乐趣，投注我们的热爱，一起愉快地做游戏，并不是特别想要追求某个特定的目标"

曾经的婉拒是为了保护团队的纯粹，而那份包容最终化作了刺向我们所有人心脏的尖刀。
